## 根因（全部真机实锤，非推测）

**问题一（折叠条位置错一格）**：用内置浏览器读取了你那个会话硬刷新后的真实 DOM——轮 5 的折叠条（`data-dsh-ta-turn="5"`）渲染在轮 5 用户消息（08:48）**上方**，且轮 5 第一个可见步骤行是 `assistant-step5:1`（**step 0 没有行**）。结合 DSH 事件类型文档（`dsh-session/lib/types/types.d.ts:227`）："turn/start 之后，**user/message 记录的是进入 step 的消息**"——即 DSH 开轮真实顺序是：

```
turn/start → step/start(step=0，pre-step) → user/message(用户消息) → chunk/tool…
```

插件的 `firstActivitySeq` 把 `step/start` 也算作活动事件，于是锚点 `firstActivitySeq - 0.5` 落在**用户消息之前**一格——折叠条就显示在上一轮末尾。这也解释了为什么有的会话（如"睡眠模式"）看起来正常：不同触发路径下 step0 与用户消息的先后可能不同，此修复对两种形态都正确。

**问题二（加载更早后无法折叠）**：DSH 打开会话只装最近 50 条事件、每次"加载更早"往前补 50 条，**切页不保证轮次边界**（`dsh-client-runtime/lib/client.js:7384`）。被切半的轮次缺 `turn/start`，引擎不为它物化折叠条，`computeRowTargets` 无 summary 一律不折叠。你那个会话单轮 99 次工具调用，事件数远超 50 条，首屏必然切坏。

**调研借鉴**（DSH 生态）：dsh-fold 的 auto-load 官方通道（`sessions.scope(sessionId).get('conversation').loadOlder()`，100ms 检查 `scrollTop≤4px`、inFlight 防并发、滚离即停）；dsh-tidychat 的空闲逐步加载+性能保护；ChatGPT-Collapser 的全局一键折叠。

## 实施步骤

### 第 1 步：修复锚点 bug（问题一，核心一行 + 测试）
- `activity-state.ts`：`firstActivitySeq` **不再由 `step/start` 记录**（它不产生任何可见行，且 DSH 的 pre-step step0 先于排队输入的 user/message 落日志）。锚点改锚在第一个"产生可见行"的事件（`assistant/chunk` / `assistant/message` / `tool/call` / `tool/result` / `llm/retry`）之前——该事件必然在用户消息之后。
- `turn/end` 冻结逻辑、`summarizeActivity` fallback 同步调整；`lastActivitySeq` 保持不动（仅用于兜底/统计）。
- 测试：新增"step0 先于 user/message"形态的用例（fixture 模拟真实事件序），断言锚点在 user 行之后；既有用例全部保持绿。
- 文档：`architecture.md` 决策 2 补充真实事件序依据。

### 第 2 步：合成折叠条（问题二）
新增 `plugin/src/client/synth.ts`（纯函数）+ projector 集成：
- 按 DOM 顺序扫描行 key：`assistant-step` 的 id `<turn>:<step>` 给出轮次号；`tool-call` 按扫描位置归属当前轮；对"有活动行但无真实折叠条"的轮次合成 `SummaryRef`（`finalStep = 最大 step`；retry 行无法归属，保持展开）。
- 优先级：真实条 > 持久缓存 > 合成；真实条物化后自动移除合成条，折叠决策无缝衔接。
- 合成条 `insertBefore` 到该轮第一个活动行之前，复用 `dsh-ta-toggle` 样式，插入幂等。
- 文案："执行步骤 N · 工具 M"；**默认折叠**（已确认），可点开。

### 第 3 步：成员快照持久化
新增 `membership-persist.ts`：localStorage `dsh.turn-collapse.membership.v1`，每会话上限 256 轮，debounce 写入；启动读回，刷新后已见过的轮次用准确数据恢复折叠。

### 第 4 步：滚动近顶自动加载更早（照搬 dsh-fold 机制 + tidychat 性能保护）
- `inject` 增加 `'sessions'`；100ms 检查 `scrollTop ≤ 4px`，直调 `scope(sessionId).get('conversation').loadOlder()`；inFlight/hasMore 防护、滚离即停；连续加载越多泵间隔越长（100ms→400ms→1s 封顶）防卡顿。
- localStorage 开关 `dsh.turn-collapse.autoLoad`（默认开）。
- 组合效果：往上滚 = 历史自动加载且自动收成"折叠条 + 最终回复"的结论流。

### 第 5 步：全局一键折叠/展开
会话列角落浮动小按钮："全部折叠"（保留最新一轮展开）/"全部展开"，批量写 store 后 reconcile。

### 第 6 步：版本标记 + 构建 + 测试 + 文档
- client 入口加 `console.info('[dsh.turn-collapse] vX loaded')` 便于确认生效版本。
- 全部单测（synth 归属、真实替换合成、持久化、auto-load 泵）+ `npm run build` + 文档更新。
